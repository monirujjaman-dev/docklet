Docklet 1.0 is a lightweight, self-hosted PaaS for a single server, built on Docker and Caddy. It runs as one 13 MB Go binary that uses about 19 MB of RAM when idle.

## Install

```sh
curl -sSL https://raw.githubusercontent.com/monirujjaman-dev/docklet/main/install.sh | sudo sh
```

## What's in 1.0

- **Apps:**
  - deploy from a registry image, or from Git with a Dockerfile
  - push-to-deploy webhooks (GitHub, GitLab, Gitea)
  - zero-downtime redeploys and one-click rollback without rebuilding
  - live logs, encrypted env vars, and resource limits
- **HTTPS:** automatic certificates through Caddy, for app domains and the panel domain.
- **Managed databases:**
  - PostgreSQL, MySQL, MariaDB and Redis
  - private by default, with a public port as an explicit toggle
  - "link to app" sets `DATABASE_URL`
  - scheduled backups with retention, download and one-click restore
- **Workers and cron:** background workers have no public route and restart on crash. Cron jobs run in one-off containers, with time zones, timeouts, an overlap policy and run history with output.
- **Monitoring:** live host and per-container CPU, memory, disk and network, with history.
- **Security:**
  - argon2id passwords and TOTP 2FA
  - CSRF protection and a strict CSP
  - secrets encrypted with XChaCha20-Poly1305
  - a hash-chained audit log of every admin action
- **Operations:**
  - encrypted self-backups (Settings, or `docklet backup`) and `docklet restore`
  - the installer backs up before upgrading
  - `docklet upgrade` with checksum verification for binary installs
  - update check in Settings

## Footprint

On a 2 vCPU VM, Docklet and Caddy together use 63.5 MB RSS when idle (21 MiB in cgroup memory). The same measurement of Dokploy (dokploy, Postgres and Traefik) gives 753.7 MB RSS (525 MiB). Full numbers and the method are in [docs/benchmarks.md](https://github.com/monirujjaman-dev/docklet/blob/main/docs/benchmarks.md).

## Assets

- `docklet-linux-amd64`, `docklet-linux-arm64`: static binaries
- `checksums.txt`: SHA-256 checksums of the binaries
- Container image: `ghcr.io/monirujjaman-dev/docklet:1.0.0` (also `:1.0` and `:latest`)
